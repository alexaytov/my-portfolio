On 16 October 2026, I gave this talk at the Technical University of Sofia for first-year students in computer science, cybersecurity, and information technology, following the [second-year session on 7 October]({{ '/talks/ai-assisted-software-engineering-second-year/' | relative_url }}).

The presentation, **AI-Assisted Software Engineering: From coding assistance to reliable autonomous workflows**, starts with a question: if AI can write code, why study computer science? Its answer is that system design, correctness, and ownership still depend on the person using the tools.

The same presentation follows a Java library-system example through a practical development workflow:

- Clarify what the software should do and the decisions a prompt leaves open.
- Understand how coding assistants, live agents, and autonomous agents differ.
- Break the work into small tasks with observable outcomes.
- Use tests and review to check the result, rather than accepting generated code at face value.
- Keep understanding and responsibility with the developer as the tools take on more work.

The closing advice is simple: explain the task, question assumptions, work in small steps, verify the result, and understand the code you submit. The slides and PowerPoint are available above.
