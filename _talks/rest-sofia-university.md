I delivered my **first official university lecture** at Sofia University St. Kliment Ohridski, introducing REST to third-year students in the Web Technologies course.

The session connected an architectural concept with the requests students encounter when building web applications. It was an opportunity to bring my experience as a software developer into the lecture hall and help students see how a browser and backend exchange information.

## Making API requests concrete

The accompanying course materials explain HTTP requests and responses, with a focus on **GET and POST**. They include examples of path and query parameters, JSON request bodies, headers, and common response codes, alongside practical API exercises.

The lecture notes, presentation, and exercises are available above in Bulgarian. They are part of the public [Web Technologies course website](https://alexaytov.github.io/fmi-web-tech/) I developed to support students throughout the course.

This lecture complements my work leading the practicum. More about that ongoing role is on the [Web Technologies teaching project]({{ '/projects/ta-web-technologies/' | relative_url }}).
