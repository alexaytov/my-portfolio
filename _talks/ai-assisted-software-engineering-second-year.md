On 7 October 2026, I gave this talk at the Technical University of Sofia for second-year students in computer science, cybersecurity, and information technology.

**AI-Assisted Software Engineering: From coding assistance to reliable autonomous workflows** explores how AI fits into software development, from suggestions while you code to agents that edit files, run tools, and work with more independence. The central idea is that generating code is only part of the job: engineers still need to understand the problem, judge the result, and maintain what they build.

Using a Java library system as a running example, the presentation covers:

- The differences between a copilot, a live agent, and an autonomous agent.
- Turning an idea into clear requirements and small, testable tasks.
- Using tests, types, and automated checks to give agents feedback.
- Reviewing both code quality and whether the implementation meets the requirements.
- Choosing a workflow that supports learning, with human oversight as autonomy increases.
