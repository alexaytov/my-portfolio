## Overview

Migrated from legacy security scanning to Checkmarx One cloud platform, modernizing application security testing with improved performance and developer experience.

## Key Improvements

### Performance
- Faster scan times with cloud scalability
- Incremental scanning support
- Parallel scan execution

### Capabilities
- Multi-engine scanning (SAST, SCA, IaC)
- Modern language support
- API security scanning
- Container image scanning

### Developer Experience
- Faster feedback loops
- Clear remediation guidance
- PR comments with findings

## Migration Approach

- Pilot with select projects
- Phased rollout in batches
- Team training and documentation
- Policy optimization
