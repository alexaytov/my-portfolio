## Overview

Master's thesis investigating the integration of Business Artificial Intelligence into enterprise applications. The research includes analysis of AI in business contexts and the development of an AI Hub application for creating and managing custom AI models and agents.

## AI Hub Application

A platform enabling businesses to:
- Register and manage custom AI models
- Create intelligent agents with specific behaviors
- Integrate multiple data sources for AI context
- Customize AI model parameters and prompts
- Deploy AI capabilities through APIs

## Technical Architecture

- **Backend**: Java Spring Framework with RESTful APIs
- **Frontend**: Angular for user interface
- **Relational Database**: MySQL for user and configuration data
- **Vector Database**: ChromaDB for semantic search and RAG support
- **AI Integration**: OpenAI and SAP AI Core Service
