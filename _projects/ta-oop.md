## Overview

Served as a teaching assistant for the Object Oriented Programming course in the Computer Science program at the Faculty of Mathematics and Informatics, Sofia University, during the Spring Semester 2024/2025.

## Responsibilities

- **Lab Sessions**: Conducted weekly practical sessions on OOP concepts and implementation
- **Code Review**: Reviewed student code for proper OOP principles and best practices
- **Office Hours**: Assisted students with understanding complex OOP concepts
- **Grading**: Evaluated assignments and provided detailed feedback

## Topics Covered

- Classes and Objects
- Encapsulation and Access Modifiers
- Inheritance and Polymorphism
- Abstract Classes and Interfaces
- Operator Overloading
- Templates and Generic Programming
- Memory Management and RAII
- Design Principles (SOLID)
