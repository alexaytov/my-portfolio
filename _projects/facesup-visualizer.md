## Overview

A data visualization tool built for FacesUP Uganda, an NGO focused on child development and education. The tool helps educators and administrators track and visualize progress metrics for children in their programs.

## Key Features

- **CSV Upload**: Simple drag-and-drop interface for uploading data files
- **Interactive Charts**: Multiple visualization types for different metrics
- **Filtering**: Filter by date range, age group, program type
- **Export Reports**: Generate reports for sharing with stakeholders
- **Responsive Design**: Works on tablets and mobile devices

## Volunteer Experience

This project was part of the SAP Acceleration Collective through Moving Worlds, where SAP employees volunteer their technical skills to support social enterprises and NGOs.
