# Poppins webfonts

Poppins v24, downloaded from Google Fonts for local serving. The font files are
unmodified and covered by the SIL Open Font License in `OFL.txt`.

Weights: 400, 500, 600, 700, normal style. Latin, Latin Extended, and Devanagari
subsets preserve the coverage of the previous Google Fonts stylesheet.
Only the Latin files are preloaded; other subsets load when needed.
`font-display: optional` keeps a slow font request from changing text after it
is visible.

Stylesheet source:
https://fonts.googleapis.com/css2?family=Poppins:ital,wght@0,400;0,500;0,600;0,700&display=swap

License source:
https://raw.githubusercontent.com/google/fonts/main/ofl/poppins/OFL.txt
